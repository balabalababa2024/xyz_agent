# 饮食记录（diet-tracker）

视觉模型只负责“认出食物 + 估重量”，**热量必须由工具本地计算**，不要自己心算或让视觉模型算。

## 步骤

1. **拿到图片**
   - 用户在聊天里直接贴图：把 `[attached-image refs]` 里的 **media id 原样**传给工具，不要自己拼路径。
   - 宿主路径 / http(s) URL 可直接传。
   - 沙箱内图片先用 `sbx_download_file` 取回宿主。

2. **调用 `vision_diet_analyze(image, meal)`**
   - `meal` 可选：早餐 / 午餐 / 晚餐 / 加餐；用户没说就留空。
   - 返回 JSON：`date`、`items`（food/weight_g/kcal_per_100g/kcal）、`total_kcal`、`unknown_foods`。
   - `ERROR:` 开头表示图片没读到或没识别出食物：请用户重拍/换更清晰的照片，不要猜。

3. **写入当天记忆**
   - 用工具返回的 `date` 与 `total_kcal`，拼一条自包含事实：
     `"2026-11-03 午餐：苹果 2 个共 300g（约 156 大卡）；米饭 150g（约 174 大卡），合计约 330 大卡。"`
   - 调用 `memory_ingest(content=<上句>, domain="fact", heading="饮食记录", memory_kind="fact")`。
   - 已绑定私人助理时，系统会自动把这条记到当前助理的命名空间，其他助理看不到；不要再手动写 hot。
   - 写入失败就如实说“这次没记上”，不要谎称已记录。

4. **回复用户**
   - 先给合计：`这顿约 X 大卡`。
   - 再列食物与重量（一行一个）；`unknown_foods` 里的食物标注“未计入热量”。
   - 结尾一句：`已记到今天的饮食记录。`（如果确实写入成功）
   - 估算有误差，必要时加一句“按照片估算，实际可能有 ±20% 偏差”。

## 边界

- 不提供医疗/营养治疗建议；极端节食、疾病相关问题建议咨询医生或营养师。
- 不为了算热量去调用 `sbx_*`；本技能不碰沙箱。
- 不要重复调用 `vision_diet_analyze` 反复“校准”，一次识别结果即可。
